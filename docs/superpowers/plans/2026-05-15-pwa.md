# PWA — Instalação no Celular — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tornar o app CCB instalável no celular (Android e iOS) como PWA, requerendo conexão com a internet para funcionar.

**Architecture:** Usa `vite-plugin-pwa` para gerar o web app manifest e registrar um service worker via Workbox com `globPatterns: []` e `navigateFallback: null` — nenhum cache offline, apenas habilita o prompt de instalação. Nginx recebe regra específica de `no-cache` para `sw.js` para que atualizações do app sejam sempre entregues. Ícones PNG gerados a partir de SVG via `sharp`.

**Tech Stack:** Vite 5, vite-plugin-pwa, sharp (devDependency), Nginx

```js
const sharp = require('sharp')
const path = require('path')

const svgPath = path.join(__dirname, '../public/icon-source.svg')

async function generate() {
  for (const size of [192, 512]) {
    await sharp(svgPath)
      .resize(size, size)
      .png()
      .toFile(path.join(__dirname, `../public/pwa-${size}.png`))
    console.log(`✓ pwa-${size}.png`)
  }
}

generate().catch(console.error)
```

## Task 3: Nginx — no-cache para sw.js

**Files:**
- Modify: `frontend/nginx.conf`

**Contexto:** O Nginx atual cacheia todos os `.js` com `Cache-Control: public, immutable` por 1 ano. O service worker (`sw.js`) nunca pode ser cacheado pelo HTTP — o browser gerencia seu próprio ciclo de atualização. Sem essa regra, o app nunca receberia atualizações após a primeira instalação.

A nova regra `location = /sw.js` deve aparecer **antes** da regra genérica `location ~* \.(js|css|...)$` para ter precedência.

- [ ] **Step 1: Atualizar `frontend/nginx.conf`**

Substituir o conteúdo completo por:

```nginx
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Proxy para o backend (evita CORS)
    location /api/ {
        proxy_pass         http://app:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_read_timeout 90;
    }

    # Proxy para uploads (fotos)
    location ^~ /uploads/ {
        proxy_pass         http://app:3000/uploads/;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    }

    # Service worker — nunca pode ser cacheado pelo HTTP
    location = /sw.js {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        expires 0;
    }

    # Cache de assets estáticos
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```
